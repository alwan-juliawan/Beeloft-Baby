# 🐝 Beeloft Baby — Landing Page

Landing page resmi untuk **Beeloft Baby**, brand pakaian anak premium dari Jakarta (sejak 2022).
Dibangun dengan HTML, CSS, dan JavaScript murni — ringan, cepat, dan responsif.

![Beeloft Baby](https://img.shields.io/badge/Beeloft%20Baby-Kidswear-EE7DA6?style=flat-square)
![Status](https://img.shields.io/badge/status-live-A8DFD0?style=flat-square)

## ✨ Fitur

- 🎨 **Palet pastel** diambil langsung dari estetika Instagram [@beeloftbaby](https://www.instagram.com/beeloftbaby/) — pink, kuning, mint, lavender, coral.
- 📱 **Fully responsive** — tampil rapi di desktop, tablet, dan mobile (dengan menu hamburger).
- 🎬 **Animasi halus** — reveal on scroll, floating elements, hover micro-interactions.
- ♿ **Aksesibel** — focus states, `prefers-reduced-motion` dihormati, semantik HTML.
- ⚡ **Zero dependency runtime** — tanpa framework, load super cepat.

## 📂 Struktur

```
Beeloft-Baby/
├── index.html          # Halaman utama
├── css/
│   └── style.css       # Seluruh styling + design tokens (palette)
├── js/
│   └── script.js       # Sticky nav, mobile menu, scroll spy, reveal
├── scripts/
│   ├── validate.js     # Lint: cek integritas file & sintaks
│   └── build.js        # Build: salin ke dist/
└── package.json
```

## 🚀 Menjalankan Lokal

```bash
# Lint (cek integritas file)
npm run lint

# Build (output ke dist/)
npm run build

# Preview lokal di http://localhost:4173
npm run preview
```

Atau langsung buka `index.html` di browser.
